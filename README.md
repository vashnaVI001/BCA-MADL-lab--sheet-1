# Dart Programming Basics — Lab Sheet 1

This repository contains solutions to all 25 programs listed in the uploaded **BCA303P-AS01.pdf** lab sheet.

## Programs
1. Display name, course, college, and semester
2. Demonstrate `int`, `double`, `String`, and `bool`
3. Demonstrate `var`, `final`, and `const`
4. Arithmetic operations on two numbers
5. Rectangle area and perimeter
6. Circle area
7. Celsius to Fahrenheit conversion
8. Swap two variables
9. Positive, negative, or zero
10. Even or odd
11. Largest of two numbers
12. Largest of three numbers
13. Leap year
14. Grade from percentage
15. Print 1 to 10 using a `for` loop
16. Even numbers from 1 to 50
17. Sum of first 10 natural numbers
18. Multiplication table
19. Factorial
20. Reverse a number using a loop
21. Function that returns the sum of two numbers
22. Prime-number function
23. List of five student names
24. Largest and smallest in a list
25. Student result using marks in three subjects

## Requirements
- Dart SDK (stable)
- A terminal or an editor such as Visual Studio Code

## Run a program
From this directory, run any file with Dart, for example:

```bash
dart run 04_arithmetic_operations.dart
```

Each `.dart` file has its own `main()` and is intended to be run independently.

## Before submitting
- In `01_display_details.dart`, replace the sample name, course, college, and semester with your own details.
- In `14_student_grade.dart`, the grading bands are example bands because the lab sheet does not specify a grading scale. Adjust them to your institution's rules.
- In `25_student_result.dart`, the pass rule assumes at least 33 marks in each subject. Adjust this if your institution uses a different rule.
